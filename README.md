# Hack Club Community PDS

Issue tracker + docs and infra repo for `pds.hackclub.community` PDS instance on Nest, powered by [Tranquil.farm PDS software](https://tangled.org/tranquil.farm/tranquil-pds).

## Request a invite

We're working on setting up a system for issuing invite codes for Hack Clubbers in the future. Stay tuned!

In the meanwhile, you can ask @ajhalili2006 via Slack DMs for one whether migrating your account from somewhere else or need an Atmosphere account for your HCB organization. Alums at Hack Club (including former staff) are welcome, altough [we recommend joining the society first](https://alumni.hackclub.community) for updates, among other things.
